# 関西釣りマップ

福井を含む関西（福井・京都・兵庫・大阪・和歌山・滋賀・奈良）の陸っぱり釣り場を、
**エリア × 魚種 × 月**の釣れ具合で見られる地図です。

**地図を開く → https://araaraai.github.io/kansai-fishing-map/**

## データの見方

- **実測**（金の縁取り）: 海釣り施設が公開している公式釣果を集計しています。
  その月の記録日のうち、その魚が釣果表に載った日の割合で4段階にしています
  （60%以上＝最盛期、25%以上＝狙えば釣れる、それ未満＝混じる程度）。
  匹数を公開している施設は、釣れた日の匹数の中央値や来場者1人あたりの匹数も表示します。
- **推定**: 釣り場ガイド記事・釣具店の情報に書かれた時期をもとにした目安です。数は測っていません。
- **釣具店の報告件数**（福井）: 釣具店に寄せられた陸っぱりの釣果報告の件数です。
  「釣れたときに届く情報」なので、量そのものではなく話題になった頻度として見てください。

各エリアの出典は地図内に記載しています。立入禁止・遊漁券・禁漁期は年ごとに変わるため、
釣行前に現地の掲示や漁協の案内をご確認ください。
